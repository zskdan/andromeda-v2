# Andromeda project tracking

This directory contains project-management views derived from the repository's
authoritative engineering records. It does not replace requirements, interface
definitions, architecture decisions, verification evidence, controller task
records, or integration manifests.

- `STATUS.md` is the latest consolidated project-health view.
- `daily/YYYY-MM-DD.md` contains the prioritized list and snapshot for a day.

Every status statement must cite a repository path or command result. Tasks
should identify applicable requirement IDs, the responsible engineering owner,
dependencies, and the evidence needed for completion. Unknown values remain
`TBD`. Implemented, verified, and validated are reported separately.
